头像：人是圆的，Agent 是方的

圆形与方形 · 双重身份编码

头像和标志用同一种东西：点。每个头像是一块实色底，上面三乘三的点阵由名字算出来，谁都不重样，没有表情脸。

统一规则：人的底图和内部点阵都使用圆形；Agent 的底图和内部点阵都使用方形。外轮廓与内部形态共同传递身份信息，颜色与点阵位置沿用原方案。

Human / 人圆形底图 + 圆形点阵
Agent / 智能体方形底图 + 方形点阵

设计原则冗余编码（Redundant Encoding）：通过外轮廓与内部点阵两种线索表达同一身份，在小尺寸或外轮廓不明显时仍提供辅助识别。
