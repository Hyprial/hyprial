# 集成放行调整：优先统一接线可用

2026-11-04 用户接受 linyilun 的建议，并授权 codex-daemon-request 自行审核调整。
本文件覆盖 00/01/02 中“每一小包必须全量全绿、所有最终门同时完成才可分阶段交付”的
执行要求；唯一调用链、身份边界与最终首次旅程目标不变。不修改 CI workflow、不绕分支保护。

## 两个里程碑

- **M1：已初始化的隔离环境统一接入。** 唯一 client/transport/FastAPI/daemon.request，
  四线 adapter、同源宿主和唯一 daemon|contract-mock 开关；必要账号/设备/初始化状态
  在启动时明确核验，未就绪返回明确状态/错误，不回退 GUI mock。普通页面已有方法走后端，
  不存在的方法明确 unavailable。先交接口小包，再逐项集成装配与宿主。
- **M2：GUI 首次旅程。** 完成原 02-common 的 BootstrapRuntime、身份事务/T11、登录/
  注册 intent、设备/初始化、HTTP 交接与回执恢复。M1 不等于 M2，不抹去 M2 工作项。
- M1 可作为标有局限的内部源码预览交付；通过其适用硬门的整候选可按既定 PR 路线
  交 release 维护者接收。不能把 release 分支代码合入等同 wheel 发布或完整产品验收；
  冷启动/wheel 未完成必须保留未结工作包、明确交付范围与后续 PR，不能写全线完成。

## 工作包 → intg

| 判定 | 要求 |
|---|---|
| 阻断 | 改动范围的 GUI typecheck/build/焦点测试；相关结构/模块边界；涉及契约时 Spec/OpenAPI/client/examples 一致；身份/权限/凭据/T11、写入 unknown 不重复、跨 generation/CSRF 等适用负例 |
| 阻断 | 另建业务桥、前端 fixture 伪装成功、绕 daemon 权威、静默吞错误、接口不兼容、数据损坏、秘密泄露、实现依赖未提供且仍对外启用功能 |
| 信息性 | 无关全量 pytest 分片、非相关平台/后端套件、已归因的基线故障、非核心样式/体验 bug；无需每个小包重复全量 |
| 平台故障 | 取包/runner/网络故障单列 BLOCKED；相关硬门可提供精确 SHA 的隔离本地等价验证供 reviewer 判断，不伪造 CI 绿。平台必需 check 若阻止合并仍按权限解决，不 force_merge/改保护 |
| 独立审核 | 保留；阻断级给 REWORK。非阻断问题给“本包 scoped PASS + 已知问题”，不得写成全量/运行时通过。公共线始终由非作者审核 |

不按“job 名一样”判断无关/基线；需要具体断言/失败阶段和变更关联。未归因的失败不自动
降为平台噪声。文档门、声明门、base freshness 等现有仓库保护仍执行；不删测试/断言过门。

## 整候选 intg → release 的 G1–G8

| 门 | M1 判定 | M2/完整交付 |
|---|---|---|
| G1 唯一调用边界 | 硬门：本次启用业务全部统一；未迁移功能明确禁用，旧代码不可仍作产品旁路 | 全部产品路径统一，清除残留业务桥 |
| G2 空 home | 可延期为已知缺口；未初始化明确拒绝/指引，不假称登录已接通 | 必须实测完整 GUI 首次旅程，注册不可用有明确契约拒绝 |
| G3 身份/T11 | 已启用路径的所有安全约束硬门；不得以未做 bootstrap 为由放宽 ready 会话/凭据边界 | bootstrap/切换/恢复全部适用负例硬门 |
| G4 四线真实接线 | 硬门：每线已启用路径至少真读、真写或真实拒绝，并能关联 requestId；缺方法的明确错误算正确行为，fixture 不算 | 补首次旅程依赖下的组合验证；非核心 UI 问题可登记 |
| G5 唯一 Mock 开关 | 硬门：同页面/build/client/path，仅宿主 upstream 不同；缺样例明确失败 | 增加 onboarding journey；不靠前端状态机模拟 |
| G6 写入不确定性 | 已启用写操作硬门：断响应、unknown、可查询回执/业务键，不重复发起 | 补 auth/initialize 与 promotion 组合 |
| G7 源码/安装态 | 源码预览可以延期 wheel，但退出仅停自有进程为硬门；不能宣传安装态可用 | wheel 交付前必须无 Node/npm/Git 实测，同协议/同旅程 |
| G8 结构/契约/CI | 结构、依赖、契约、类型/构建、相关焦点为硬门；全量组合回归集中跑一次，非相关/平台失败可登记 | 同原则；不要求每小包都重跑无关全量，不将未跑项标 PASS |

实际外部 IdP/provider 不可访问则相应能力为 BLOCKED；允许其他已验证能力进入限定 M1
交付，不能把模拟测试当真实授权。明确保留风险/不可用说明，不通过隐藏入口造成“全覆盖”假象。
