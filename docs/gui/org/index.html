API 规则

  • 所有 org 线 HTTP 方法都是 POST /daemon/request/<method>。
  • 浏览器不能自报 from / sessionRef / onBehalfOf；link.add/drop 用 local-owner-selector。
  • link.list/stats 用 local-operator-selector；orgfs.export/import 用 local-owner-selector。
  • ACL 三个方法 http_exposed=false，不生成 OpenAPI、不进浏览器 bundle、GUI 不提供入口。

附录 F · 结论

已经完整接通

  • 创建、创建结果判定、修复预览/应用、发布本机记录。
  • 邀请生成、链接加入、四步 bootstrap 反馈；重复加入跳过。
  • 组织列表、详情聚合读取、手动刷新、org.fetch 同步、单路失败未知态。
  • 离开组织；link.list/add/drop；OrgFS 读、写、建、移、删、历史（含版本读取）。

明确受限 / 仍需后端

  • 17 个 GUI 动作没有 daemon 方法：待处理邀请、切换当前组织、改名、模板/导入/配置候选/采信、Agent-org、迁移全流程。
  • org.delete 有 MethodSpec/HTTP/GUI，但 daemon 固定 LAST_AUTHORITY_REFUSED，需要独立的确认关停维护流程。
  • 人员/Agent 目录、组织配置、统计在 live detail 中为 null，目前只有 fixture 数据；成员移除因此有 API 但入口不可达。
  • OrgFS 目录恢复、条目级彻底清除未实现；GUI 分别返回 ORG_FOLDER_RESTORE_UNSUPPORTED 与 ORG_PURGE_UNSUPPORTED。
  • Contract Mock 不再是功能缺口：未来完整 intg 预期 60/60；但 #2297 仍需 merge-forward。合并后剩余问题都是 daemon/产品语义，不是 mock 例子。
