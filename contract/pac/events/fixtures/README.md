- snapshot reports actual migration `cursorFloor=2`; positive `after=1` with the

This exercises the implemented **migration/import floor**, not a hypothetical
retention job. It does not claim that a pre-contract flag seq was a public cursor,

and immutable, checks integrity/FKs, and compares its entire dump to the SQL.
