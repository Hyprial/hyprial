创建 Agent

名称与职责必填。模型凭据不在此处配置：创建后到详情页授予。字段对齐 hyprial agent create（hyprial 只有 agent / harness / model 三级概念）。

对应 --name：Agent 在本机的身份名，被删除前不可复用。

对应 --provider：模型厂商偏好；默认跟随所选模型服务。

对应 --model：模型 id 偏好，可留空。

对应 --preferred-harness：仅作为默认，Agent 不被绑定到该 harness。

创建凭据说明：若账号已记录默认服务商登录，新 Agent 将自动获得授权；否则创建完成后在详情页引导绑定。

「模型服务」概念已删除：无模型服务下拉，创建不被模型凭据门控；新增服务商 / 模型 / 首选 harness 三项偏好（均可选）。提交仍走网关接缝，未接后端显示「Agent 创建暂不可用」。
